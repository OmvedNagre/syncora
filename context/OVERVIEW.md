# Syncora Project Overview

## What is Syncora?
Syncora is a modern, real-time collaboration workspace built with a Discord-like layout and interaction model. It allows creators, engineers, and study groups to instantly spin up an ephemeral, encrypted "Sanctuary" without account creation, sign-up forms, or persistent database tracking.

## Core Capabilities

| Feature Area | Description |
| :--- | :--- |
| **Categorized Channels** | Dedicated text channels (`#general`, `#ideas-and-links`, `#music-jam`), voice lounges (`Lounge Voice`, `Focus Pod`), and activities (`Watch Party`, `Pair Sandbox`, `Tasks & Sprints`). |
| **Low-Latency Voice & Video** | Real-time WebRTC audio with Web Audio API speaking rings, native webcam video calling, and self-preview screen sharing. |
| **Discord Communication UX** | Persistent bottom-left voice status, attached connection diagnostics popover with live ping sparkline, inline message replies, and quick reactions. |
| **Synchronized Media Player** | HD video synchronization with synchronized play/pause/seek, custom presets, and slide-out Theater Chat drawer. |
| **Collaborative Code Sandbox** | Real-time shared editor supporting JavaScript, Python 3, and TypeScript execution with synchronized terminal output. |
| **Team Task Management** | Milestone checklists with progress bars, user attribution, filter pills, and celebration confetti. |
| **Ephemeral Security & Burn Protocol** | Room-level AES-GCM / WebRTC encryption with an irreversible 10-second shredding protocol that completely wipes the room state. |

## Target Persona & Use Cases
1. **Pair Programmers & Hackathon Teams**: Spin up a space with dedicated voice, shared sandbox, and to-do sprints in under 5 seconds.
2. **Creative Study Groups & Lounges**: Drop in for focus work, listen to lo-fi streams in Watch Party, and talk over low-latency voice.
3. **Privacy-Conscious Creators**: No permanent chat logs, no tracking cookies, ephemeral memory lifecycle.
